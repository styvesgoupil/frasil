Install from the browser

  1. Connect the FM-1 by USB.
  2. In Chrome or Edge, open FRASIL on The FM-1 Firmware Hub.
  3. Press Install. Allow MIDI when the browser asks.
  4. Don’t unplug the cable while it writes.

Install from a terminal

Download frasil-X.Y.fwsc from the releases. In a checkout of FRASIL’s repository, run:

python3 base/tools/fm1_install.py frasil-X.Y.fwsc

Back to the official firmware

Install M-VAVE’s V15 from the installer or The FM-1 Firmware Hub. If the FM-1 won’t start, hold OCT− while you switch it on: it waits for an update over USB.

Your scenes when you switch firmwares

  • Back up your scenes first (FRASIL 1.1 and later): in the River (Chrome or Edge) or with base/tools/fm1_backup.py. See backing up.
  • Updating FRASIL keeps your scenes. M-VAVE’s V15 erases them. Other firmwares may too.
  • Saving in FRASIL can overwrite another firmware’s data (Felucca’s settings, projects and samples). Back that firmware up before you save.
  • FRASIL ignores other firmwares’ data. With none of its own, it starts with its factory scenes.

Versions

The logo screen shows the version the FM-1 runs. The package is named FM-1_47XXYYZZ: 2.0 is FM-1_47020000.

From source

For forks: the host simulator, the checks, the browser emulator and the firmware.

git clone --recursive https://github.com/styvesgoupil/frasil
cd frasil
python3 -m venv .venv && .venv/bin/pip install Pillow fonttools mido python-rtmidi numpy scipy matplotlib
brew install libraqm                     # the screen's fonts (macOS)

./build.sh --host                        # the host simulator: app/build/host/frasil_host
app/build/host/frasil_host app/tests/basic.txt app/build/host      # the checks
./build.sh --web                         # the browser emulator: app/build/emu/ (Emscripten)
./build.sh                               # the firmware: app/build/frasil-VERSION.fwsc

The firmware build needs JieLi’s toolchain and the AC79 SDK in Docker. See fm1-base’s README.
